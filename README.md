# SenaPay-DEF 

Billetera digital formativa que permite a aprendices e instructores del SENA pagar su comida sin efectivo, mediante panel de aprendiz, panel de tienda y un módulo de pagos vía API REST.

Proyecto presentado formalmente ante el SENA (Ficha 3232476, ADSO) — **desarrollo completado hasta fase beta funcional**.

---

##  El problema

En el comedor del CIMM (SENA, Regional Boyacá), los pagos en efectivo generan filas largas, riesgo de pérdida de dinero y dificultad para llevar control de consumo. SenaPay-DEF resuelve esto con una billetera digital cerrada, pensada específicamente para el ecosistema de una ficha SENA.

## funcionalidades

- **Panel de aprendiz:** consulta de saldo, historial de movimientos, recarga.
- **Panel de tienda:** cobro digital, registro de ventas, conciliación de caja.
- **Módulo de pagos:** flujo de transacción end-to-end vía API REST propia.
